## 2. Giới thiệu

Đây là repository tổng hợp kết quả thực hành JavaScript
trong học phần Phát triển ứng dụng Thương mại điện tử.

Bài thực hành gồm 3 Lab với tổng cộng 29 Exercise,
tập trung vào kiến thức nền tảng JavaScript, thao tác
DOM, xử lý sự kiện và sử dụng thư viện jQuery.

## 3. Nội dung các Lab

### Lab 08 – JavaScript 1: Language Foundations

Gồm 11 Exercise, tập trung vào:

- Cú pháp JavaScript và cách nhúng JavaScript vào HTML.
- Biến, kiểu dữ liệu, hàm và các đối tượng JavaScript.
- String, Date, Math, Array và Object.
- Kiểm tra kết quả bằng Browser Console.

### Lab 09 – JavaScript 2: DOM and Events

Gồm 8 Exercise, tập trung vào:

- Truy xuất và thao tác với DOM.
- Thêm, xóa và cập nhật phần tử HTML.
- Xử lý các sự kiện tương tác.
- Debugging bằng Chrome DevTools.
- Xử lý và kiểm tra dữ liệu biểu mẫu.

### Lab 10 – JavaScript 3: jQuery

Gồm 10 Exercise, tập trung vào:

- Thiết lập thư viện jQuery.
- Sử dụng Basic và Advanced Selectors.
- Xử lý sự kiện và thao tác DOM.
- Tạo hiệu ứng Fade, Slide và Animation.
- GET Requests và xử lý jqXHR.
